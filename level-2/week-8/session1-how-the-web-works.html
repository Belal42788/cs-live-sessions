الإنترنت: الشبكة اللي بتوصل العالم كله

الإنترنت شبكة عملاقة

تخيّل إن كل بيت في العالم بيبقى جهاز كمبيوتر، والطرق اللي بتوصل البيوت ببعض هي الـ Internet. الإنترنت بيوصل بلايين الأجهزة في العالم كله بأي معلومة عايزين نتبعت.

وأهم حاجة: أي معلومة بتتبعت بتتقسم لقطع صغيرة اسمها Packets 📦، وكل قطعة تسافر لوحدها، وبعدين تترجع تتجمع تاني لما توصل.

📤 Data Transfer

البيانات بتتقسم لـ Packets.

⚡ Always On

⚠️ أخطاء مشتركة

  • الظن إن الإنترنت "حاجة في السما" — لأ، فيه بنية تحتية حقيقية من كابلات وأبراج.
  • الظن إن الرسالة بتتبعت كقطعة واحدة — لأ، بتتقطع لـ Packets بتسافر لوحدها.
  • الخلط بين الإنترنت والويب — لا، دول حاجات مختلفة وهنفهم الفرق في الركن التاني.

الويب مقابل الإنترنت

الإنترنت = الطرق، الويب = المحلات

الإنترنت هو البنية التحتية (الطرق)، والويب خدمة بتشتغل فوقها (المحلات والأماكن اللي بتزورها). مش كل استخدام للإنترنت بيبقى ويب! واتساب بيستخدم إنترنت لكن مش ويب، أما يوتيوب في المتصفح بيستخدم الاتنين.

Createdاتأسس الأول (أنذر زمن)جاي بعده وجايب منه
Examplesكابلات، معرّفات، أندواتمواقع وصفحات

الموقع مقابل الصفحة (Website vs Web Page)

الموقع = كتاب، الصفحة = صفحة جواه 📖

الـ Website مجموعة صفحات تحت نفس العنوان. الـ Web Page صفحة واحدة بس. مثال: ويكيبيديا موقع كامل، ومقال مصر واحد صفحة جواه.

الـ URL: عنوان أي حاجة على الويب

الـ URL بيفصل العنوان لأجزاء واضحة 🔍

الـ URL هو العنوان الكامل لأي صفحة، وفيه أجزاء لكل واحد دور. اضغط على كل جزء وشوف بيعمل إيه:

https:// www.example.com :443 /path/page.html ?query=1
اضغط على أي جزء من العنوان 🤓

📝 اختبر نفسك

في عنوان زي https://example.com/page.html، إيه اسم الجزء https://؟

⚠️ أخطاء مشتركة

  • الظن إن الـ URL هو اسم الموقع كله — لأ، هو عنوان كامل.
  • الخلط بين الـ Protocol والـ Domain.

الطلبات والردود: HTTP

لغة الطلب والرد بين المتصفح والسيرفر 💬

عندك HTTP Request (المتصفح بيطلب) و HTTP Response (السيرفر بيرد). دي كلها بتحصل في أجزاء من الثانية. اضغط وشوف زوج طلب/رد:

📤 Request

GET / HTTP/1.1
Host: www.example.com

📥 Response

HTTP/1.1 200 OK
Content-Type: text/html

💡 فعلًا ده اللي بيحصل ورا كل زيارة

كل مرة بتفتح فيها موقع، بتتحرك مئات الطلبات والردود، وكل واحد ليه كود حالة إجابي أو خطأ.

كودات الرد أشهرها وأهمها 🏷️

الكودالمعنىمثال
200نجحتم تحميل الصفحة
404غير موجودرابط مكسور
301اتحولاتنقل الموقع
500خطأ في السيرفرعطل عند السيرفر

📝 اختبر نفسك

إذا شفت الكود 404، يعني إيه؟

⚠️ أخطاء مشتركة

  • الخلط بين 404 و 500 — 404 عن الصفحة، و500 عن السيرفر نفسه.
  • الظن إن الـ Request والـ Response بيتعملوا مرة واحدة بس.
