إيه هو الـ CSS؟

Content vs Presentation

في الصفحة حاجتين مختلفتين: الـ Content (إيه اللي موجود في الصفحة — ده الـ HTML)، والـ Presentation (شكلها إزاي — ده الـ CSS). الـ CSS بيستهدف عناصر HTML موجودة أصلاً، مش بيضيف محتوى جديد.

«الـ HTML بيبني الأوضة، والـ CSS بيدهنها ويرتبها.»

جرّب الفرق بنفسك

CSS بيغيّر شكل الموجود

النص ده هو الـ Content. شوف إيه اللي بيحصل لما نضيف CSS.

●●●style.css
/* قبل */ h1 { color: black; font-size: 26px; } p { color: #333; } /* بعد */ h1 { color: blue; font-size: 32px; } p { color: green; }

⚠️ أخطاء شائعة

  • بنفكر إن الـ CSS بيضيف محتوى جديد — لأ، بيغيّر شكل الموجود بس.
  • نسيان تحويل الـ CSS جان الـ file منفصل في مشروع حقيقي.
CSS بيعمل إيه بالظبط؟
لأ، الـ CSS مبيضيفش محتوى — بيستهدف عناصر HTML موجودة أصلاً.
صح! الـ CSS مبيغيرش الـ Content، بيلوّن الـ Presentation بس.
خلّي عندك، عدّي السؤال
01

صياغة قاعدة الـ CSS

Selector + Property + Value

أي قاعدة CSS مبنية من 3 أجزاء: الـ Selector (العنصر المستهدف)، الـ Property (الخاصية)، والـ Value (القيمة)، كلها جوه { } وبعد كل قيمة ;.

●●●syntax.css
h1 { color: blue; } ↓ selector ↓ property ↓ value

⚠️ أخطاء شائعة

  • نسيان ; آخر القيمة.
  • كتابة الـ property اسمه غلط (مثل text-weight بدل font-weight).
في p { font-size: 18px; }، إيه الـ Property وإيه الـ Value؟
لأ، الـ p ده الـ selector — بيختار العنصر.
صح! font-size هي الـ property، 18px هي الـ value.

02

إزاي نوصل الـ CSS بالـ HTML

Inline / Internal / External

في 3 طرق نكتب بيها الـ CSS. المهم: الطريقة الاحترافية والمعيار في أي مشروع حقيقي هي External — ملف .css منفصل موصول بـ <link>.

بنكتب الـ CSS جوه العنصر نفسه بسلالة style. سريع للتجربة، بس مش منظم وصعب التعديل.

inline.html
<h2 style="color:red;">Hello</h2>

بنكتب الـ CSS جوه نفس الصفحة بين <style> و</style>. مناسب للتجارب الصغيرة.

internal.html
<style> h1 { color: red; } </style>

ملف CSS خارجي منفصل نربطه بالصفحة. الأكثر استخداماً، بيخدم أكتر من صفحة، سهل التعديل.

index.html
<link rel="stylesheet" href="style s3.css">

⚠️ أخطاء شائعة

  • نسيان الـ rel="stylesheet" — السبب الأكثر شيوعاً أن الـ style مبيشتغلش.
  • كتابة اسم الملف غلط: styles.css بدل style.css.
  • الملف في فولد فرعي من غير تحديد المسار.
أي طريقة هي المعيار الاحترافي لمشروع حقيقي؟
الـ Inline وInternal بيسيبوا كود مكرر ويصعّبوا التعديل.
صح! الـ External منظم، بيخدم أكتر من صفحة، سهل التعديل.

الألوان: color و background-color

Named / Hex / RGB / RGBA

خاصية color بتلوّن نص العنصر، وbackground-color بتلوّن خلفيته. في 4 طرق (زي ما في style s3.css): اسم اللون، Hex، RGB، RGBA بدرجة شفافية.

هنا النص اللي بيتلوّن
اسم اللون
Hex
RGBA Alpha 0.5
style s3.css
/* 1) اسم اللون */ #main-title { color: blue; } /* 2) Hex: ff أحمر 00 اخضر 00 ازرق */ #main-title { color: #0000ff; } /* 3) RGB: كل قيمة من 0 لـ 255 */ #main-title { color: rgb(0,0,255); } /* 4) RGBA + Alpha (الشفافية من 0 لـ 1) */ #main-title { color: rgba(0,0,255,0.5); }

⚠️ أخطاء شائعة

  • الخلط بين color (لون النص) وbackground-color (لون الخلفية).
  • كتابة قيمة الـ Alpha غلط — لازم تكون من 0 لـ 1، مش من 0 لـ 255.
color: rgba(255,0,0,0.5); — الـ 0.5 ده معناه إيه؟
لأ، الـ 0.5 جزء للـ alpha مش من قيمة اللون.
صح! alpha بيحدد الشفافية من 0 لـ 1.

التحكم في النص

Typography + width

خصائص تنسّق النص وتخليه شكل كويس. كلها من `style s3.css` — جرّب بنفسك دلوقتي:

النص ده بيستجيب لخصائص تنسيق النص.

font-family
font-size px
font-weight 400

width%
style s3.css
p { text-align: center; font-family: Arial; font-size: 18px; font-weight: 400; line-height: 1.6; text-decoration: none; width: 100%; }

نصايح من المصدر: line-height بين 1 لـ 2 و1.6 احترافي للقراءة؛ font-size لازم معاها وحدة px؛ width بيقبل قيمة ثابتة (100px) أو نسبة من عرض الأب (50%).

⚠️ أخطاء شائعة

  • نسيان ; آخر القيمة.
  • نسيان الوحدة: font-size:20 غلط — الصح 20px.
  • كتابة اسم الخاصية غلط: text-weight غلط — الصح font-weight.
  • نسيان إغلاق }.
font-size:20; من غير وحدة — بيعمل إيه؟
لأ، من غير وحدة المتصفح مبيقدرش يحدد القيمة.
صح! لازم وحدة قياس مع الـ font-size.

الكلاسات (Classes) والـ IDs

التحكم الدقيق

عناصر الوسم (h2, p) بتستهدف كل العناصر من نفس النوع. بس لو عايزين نتحكم في عناصر معيّنة؟ هنا بييجي دور class (بنقطة) والـ id (بالـ #).

العنوان الأول

العنوان التاني

العنوان التالت

نفس الـ 3 h3 — جرب الفرق بين Class و ID.

style.css
.highlight { color: orange; } #unique { color: cyan; }

الدليل: هيتكرر العنصر أكتر من مرة؟ → استخدم Class. قسم فريد مره واحدة؟ → استخدم ID.

⚠️ أخطاء شائعة

  • استخدام # مع class: #description غلط — الصح .description.
  • استخدام . مع id: .main-title غلط — الصح #main-title.
عنصر هيتكرر في الصفحة كذا مرة بنفس الشكل — تستخدم Class ولا ID؟
صح! الـ class قابل للتكرار على أكتر من عنصر.
لأ، الـ ID لازم يكون فريد مرة واحدة — الـ class هو ده القابل للتكرار.

نشاط: صفحة البروفايل الشخصية

نبنّيها بنفسنا

المطلوب: صفحة بروفايل شخصية فيها <h1> بالاسم (بـ ID)، <img> صورة شخصية، <p> بايو (بـ Class)، <button> "Contact Me"، <a> لينك موقع مفضل — كل ده جوه ملف style.css خارجي منفصل.

الخاتمة المطلوبة: خلفية الصفحة مش بيضاء، لونين نص مختلفين، خط مختلف عن الافتراضي، محاذاة في النص، Class واحد على الأقل، ID واحد على الأقل.

style.css — الحل
body { background: gray; font-family: Arial; text-align: center; } #main-title { color: blue; font-size: 40px; } .description { color: green; font-size: 18px; line-height: 1.6; } img { width: 200px; } button { background: orange; color: white; } a { color: red; text-decoration: none; }

من HTML بس لصفحة مصممة

Content (HTML) → Selector/Property/Value → طريقة الربط External → لون ونص → Class/ID → صفحة كاملة مصممة.
