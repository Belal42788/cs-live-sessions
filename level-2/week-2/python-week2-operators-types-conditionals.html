×ترتيب الأولويات — PEMDAS

لما تتخلط العمليات كلها في تعبير واحد، Python مش بتمشي بالعرضي. ليها قاعدة ثابتة اسمها ترتيب الأولويات — اتفق على السلّم من فوق لتحت:

1) الأقواس أولًا — أي حاجة جوه ( ) بتتنفذ الأول.

(10 + 2) * 5 = 60 ← الأول الجمع جوه القوس، وبعدين الضرب.

2) الأسس — بعدين الأس (**).

2 + 3 ** 2 = 11 ← الأس أولًا يعمل 9، وبعدين الجمع.

3) الضرب والقسمة — من الشمال لليمين (وبتوازي معاه // و %).

10 * 2 // 5 = 4 ← نضرب 20 ثم نقسمها على 5.

4) الجمع والطرح — آخر حاجة، من الشمال لليمين أيضًا.

10 - 2 + 5 = 13 ← 10 ناقص 2 = 8 ثم + 5 = 13.

التعامل مع النصوص: Concatenation و Repetition

الـ String مش مجرد تسطير — سلسلة حروف Python بيفهمها كقيمة واحدة.

"إيه هو النص/الـ String؟

الـ String سلسلة حروف بين علامتي اقتباس " " أو ' '. دي "قاعدة الاقتباسات": من غيرها Python بيفسّر الكلمة كاسم متغير أو أمر ويرميك خطأ. والنص بيخزن حروفه جنب بعض زي قطع بازل.

🧩 🧩 🧩

الغراء (+) رفيع — مش بيضيف مسافة لوحده، لازم تحط " " بنفسك.

Concatenation: "Mazin" + "!" = Mazin! — التزق بجانب.

Repetition: "*" * 20 = عمل خط فاصل بطول 20 — أسرع بكتير من الكتابة.

اتخاذ القرارات: if / elif / else

الكود بيمشي زي قطار — لكن الـ Conditionals بتحولها لمفترق طرق.

🚪الـ if زي بوابة

الكود عادة بيمشي من فوق لتحت زي قطر على سكة واحدة، لكن الـ if بتعمل "مفترق طرق": لو الشرط True البوابة بتفتح وبيخش البرنامج — لو False بيعدّي من جنبها ويستمتع بالطريق العادي.

الشرط
temperature > 25
🚪
الشرط temperature > 25 لو كان True — البوابة اتفتحت وجوه الشارع.
الشرط temperature > 25 لو كان False — البرنامج بيعدّي من جنب البوابة ويستمر في الطريق العادي.

لازم نقطتين : في آخر جملة الـ if، وبعدها سطر الكود اللي "ملك" الشرط بيتكتب بمسافة بادئة (Indentation) — غالبًا 4 مسافات.
