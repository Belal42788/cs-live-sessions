الـ Embedded System

معمول لوظيفة واحدة أو شوية وظائف محددة بس — زي الغسالة اللي بتحكم في المياه والدوران، أو الباب الأوتوماتيك بيفتح ويقفل. بيكون جوه جهاز أكبر.

مكونات أي Embedded System

أي جهاز ذكي بيتكون من 4 حاجات أساسية

🧠

Processing

المخ — الـ Microcontroller أو الـ Processor — بينفذ البرنامج وياخد القرارات.

👆

Input

الزرار أو الـ Sensor — بيدي الجهاز معلومات عن العالم الخارجي.

💡

Output

الموتور أو الـ LED أو الـ Buzzer أو الشاشة — بينفذ فعل في العالم الحقيقي.

{ }

Program

البرنامج اللي بيحدد الجهاز يعمل إيه وإمتى — هو اللي بيربط الـ Input بالـ Output.

اختبر فهمك — الباب الأوتوماتيك

الحساس اللي بيحس بوجود شخص — يعتبر Input ولا Output؟

الموتور اللي بيفتح الباب — يعتبر Input ولا Output؟

MicroPython — الأسس

دي نسخة خفيفة من بايثون معمولة للمicrocontrollers. لو تعرف بايثون، الصورة هتكون مألوفة لك.

📦 استيراد المكتبات

قبل ما تتحكم في أي حardware، لازم تستورد المكتبة الصح.

from machine import Pin import time

🔌 إعداد الأرجل

كل رجل GPIO ممكن تكون Input أو Output.

led = Pin(2, Pin.OUT) button = Pin(0, Pin.IN)

💡 التحكم في الإخراج

Pin.OUT = تحكم في شيء (لمبة، موتور). value(1) = شغّل، value(0) = أطفئ.

led.value(1) # شغّل اللمبة led.value(0) # أطفئها

📥 قراءة المدخلات

Pin.IN = تقرأ معلومة من الخارج. القيمة 0 أو 1.

val = button.value() if val == 1: print("الزرار اتداس!")

⏱ التوقيت sleep()

بيوقف الكود شوية. المدة بالثواني.

import time time.sleep(2) # وقف ثانيتين

🔄 الحلقة اللانهائية

ال ESP32 بيشتغل 24/7 — الحلقة بتخلي الكود يشتغل دايمًا.

while True: led.value(1) time.sleep(1) led.value(0) time.sleep(1)

💡 نصائح مهمة

• Pin.IN = الإدخال (زرار، حساس) — الـ ESP32 بيقرا القيمة
• Pin.OUT = الإخراج (LED، موتور) — الـ ESP32 بيتحكم فيه
• value(1) = HIGH = شغّل | value(0) = LOW = أطفئ
• لازم تكتب while True: عشان الكود ما يتوقفش
• شغل الكود بالخطأ ممكن يحرق المكونات — راجع التوصيل قبل ما تشغّل!
